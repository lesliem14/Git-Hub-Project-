CLOUDFLARE PAGES — upload this zip
==================================

Use:  ai-agent-cloudflare.zip  (repo root or download/ folder)

WHAT CLOUDFLARE EXPECTS
-----------------------
• index.html must be at the TOP LEVEL of the upload (not inside a parent folder).
• This zip is built that way: unzip and you see index.html + open/ + _redirects immediately.

PAGE ORDER (important)
----------------------
1. Visitors open YOUR-SITE.pages.dev/  →  AI Agent Guide (index.html) FIRST.
2. IDE compiler is ONLY at /open/  →  linked from “Development Site: Click Here” on the guide.
   Do NOT set the project default route to /open only — upload both index.html and open/.

STEPS (Direct Upload)
---------------------
1. Cloudflare Dashboard → Workers & Pages → Create application → Pages.
2. Choose "Upload assets" / Direct Upload (not Git if zip gives you trouble).
3. EITHER:
   A) Upload ai-agent-cloudflare.zip and let Cloudflare extract it, OR
   B) Unzip on your computer, then drag ALL files and folders
      (index.html, open, _redirects, _headers, *.js, *.css) into the upload box.
      Do NOT upload only a single wrapper folder without opening it first.

4. Deploy. Wait until status is "Success".

5. Test:
   https://YOUR-PROJECT.pages.dev/
   https://YOUR-PROJECT.pages.dev/open/

WORKERS (workers.dev)
---------------------
If you use a Worker with static assets, upload the SAME unzipped files as the
asset bundle. Route /open/* to open/index.html. Pages + _redirects is easier.

FILES IN THIS ZIP (both pages)
------------------------------
Page 1: index.html, styles.css, app.js, contract.js, site-config.js
Page 2: open/index.html, open/css/*, open/js/*, open/vendor/*, open/assets/icon.svg
Shared: contract.js, _redirects, _headers

TROUBLESHOOTING
---------------
• Blank /open/ → open/ folder missing from upload.
• Guide works, IDE broken → upload contract.js at site root (same level as index.html).
• 404 on / → index.html not at upload root; re-upload using steps above.
• Old layout → hard refresh or purge Cloudflare cache.
