CLOUDFLARE — FIX “KEEPS LOADING” ON VISIT
==========================================

USE:  idecompiler-cloudflare-v6.zip  (from repo root or ai-agent-site/)

WHY VISIT SPINS FOREVER
-----------------------
1. Worker project with NO static files attached — only a script runs; there is no index.html.
2. Upload put index.html inside a nested folder (not the project root).
3. Old bundle used ?view=ide and hid the page before JavaScript loaded.

v6 shows the full guide in HTML immediately (inline fallback styles + 404.html).

CLOUDFLARE PAGES (recommended)
--------------------------------
1. Workers & Pages → Create → Pages → Upload assets.
2. Upload idecompiler-cloudflare-v6.zip (or unzip and drag ALL files to the ROOT).
   Must include at top level: index.html, styles.css, app.js, open/, _redirects, _headers
   Do NOT add _routes.json — not used for static upload (Pages Functions only).
3. Deploy → Success → Purge cache.
4. Visit: https://YOUR-PROJECT.pages.dev/   (trailing path must be / only)

Test: you should see “AI Agent Guide” in under 1 second.

CLOUDFLARE WORKERS (*.workers.dev)
----------------------------------
Uploading HTML in the dashboard is NOT enough unless static assets are bound.

Option A — Wrangler (from repo after build-cloudflare-zip.sh):
  cd ai-agent-site/cloudflare
  npx wrangler deploy

Option B — Dashboard: Workers → your worker → Settings → Static Assets → attach
  the same files as the zip (index.html at asset root).

If Visit opens workers.dev and never finishes, you are almost certainly missing static assets.

Development Site → IDE overlay (or open/embed.html?dev=1&embed=1)
