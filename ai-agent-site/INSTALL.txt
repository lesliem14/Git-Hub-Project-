IDE Compiler — what you need for BOTH webpages
==============================================

YES — one zip has everything:

  idecompiler-install.zip

Unzip it and upload EVERY file and folder inside to your host
(keep the same folder structure).

REQUIRED FOR PAGE 1 (AI Agent Guide at /)
-------------------------------------------
  index.html
  styles.css
  app.js
  contract.js
  site-config.js

REQUIRED FOR PAGE 2 (IDE at /open/)
------------------------------------
  open/index.html
  open/css/     (all 6 .css files)
  open/js/      (all 14 .js files)
  open/assets/icon.svg
  contract.js   (same file at root — IDE loads ../contract.js)

REQUIRED FOR CLOUDFLARE
-----------------------
  _redirects

OPTIONAL
--------
  download.html, idecompiler-install.zip, downloads/*.zip
  Documentation (*.md, INSTALL.txt)
  ide.html, open.html, ide.css, ide.js (old redirects — not needed if you use /open/)

NOT ENOUGH FOR BOTH PAGES
-------------------------
  idecompiler-site.zip (9 files only) — guide + old compiler, NO full /open/ IDE

After upload:
  Page 1: https://YOUR-HOST/
  Page 2: https://YOUR-HOST/open/

See FILES-REQUIRED.md for the full checklist.
